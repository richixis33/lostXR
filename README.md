# LostXR (PhoneXR) 🥽

**LostXR** — это высокопроизводительный нативный Virtual Reality (VR) рантайм, разработанный для Android-смартфонов в связке с мобильными VR-гарнитурами (Google Cardboard, Samsung Gear VR и универсальными оптическими шлемами).

Проект превращает обычный смартфон в полноценную автономную 6DoF XR-платформу за счет низкоуровневого графического рендеринга на Vulkan и алгоритмов компьютерного зрения.

---

## 🌟 Ключевые возможности

* **Графический конвейер Vulkan 1.1**: Прямой рендеринг на экран с минимальным оверхедом, обеспечивающий стабильные 60–90 FPS и низкую задержку отрисовки (draw-call latency).
* **Позиционный 6DoF-трекинг (ARCore)**: Полноценное отслеживание головы по шести степеням свободы (inside-out) на базе слияния данных сенсоров (IMU + визуально-инерциальная одометрия через Google ARCore).
* **AI-трекинг рук и жестов (MediaPipe)**: Захват 21 ключевой точки кисти в 3D реального времени через камеру смартфона — без внешних контроллеров.
* **Низкая задержка движения к фотону (Motion-to-Photon)**: Оптимизированный цикл опроса сенсоров с предиктивной коррекцией позы головы для предотвращения укачивания.
* **Широкая совместимость**: Поддержка профилей Google Cardboard, кейсов Samsung Gear VR и универсальных гарнитур-держателей.

## 🏗 Архитектура и стек технологий

| Уровень | Технология |
| :--- | :--- |
| **Ядро и движок** | C++17 / C++20 |
| **Android Framework** | Kotlin, Java (Android NDK) |
| **Графический API** | Vulkan 1.1 |
| **Inside-Out трекинг** | Google ARCore SDK |
| **Распознавание рук** | Google MediaPipe |
| **Система сборки** | Gradle, CMake, Ninja |

---

## 📱 Системные требования

* **ОС Android**: Android 9.0 (Pie) или выше (API Level 28+)
* **GPU**: Adreno 600+ / Mali-G72+ с аппаратной поддержкой Vulkan 1.1
* **Поддержка ARCore**: Смартфон должен входить в [официальный список поддерживаемых устройств Google ARCore](https://developers.google.com/ar/devices)
* **Камеры**: Рабочая основная камера для 6DoF; фронтальная или основная камера для трекинга рук MediaPipe
